# Angry Monkey Tower Defence

Angry Monkey is a tower defense game inspired by popular Balloon TD6. In this game, player needs to strategically place monkeys around the map tiles to defend against waves of balloons. Failing to stop them from passing through will decrease player health & the Game will be Over if health reaches to 0. For every balloon being destroyed, player gets money which can be used to buy more monkeys to defend from the next wave of balloons.
This project was developed in Unity with MVC, Service Locator & Dependency Injection design patterns
